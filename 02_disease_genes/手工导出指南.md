# 受阻数据库手工导出指南（GeneCards / DisGeNET / OMIM / CTD）

> 2026-09-22 实测：以下四库均无法程序化抓取（反爬/需注册）。请按本指南在浏览器手工导出，将文件放入 `snakebite_TMA/02_disease_genes/manual/`，我收到后自动并入总表并做阈值敏感性分析。

## 1. GeneCards（主分析阈值来源，最重要）

1. 打开 https://www.genecards.org/ ，逐词检索（6 个词分别检索）：
   `thrombotic microangiopathy`、`snakebite envenoming`、`venom-induced consumption coagulopathy`、`microangiopathic hemolytic anemia`、`atypical hemolytic uremic syndrome`、`thrombotic thrombocytopenic purpura`
2. 结果页点击 **"Export"**（导出为 Excel/CSV；需免费账号登录）。
3. 命名：`genecards_<检索词英文简写>.xlsx`（如 `genecards_tma.xlsx`）。
4. **记录每个词的命中总数与导出时间**（写入文件名旁注或直接告诉我）。

## 2. DisGeNET

1. 注册 https://disgenet.com/ 免费学术账号 → 个人页生成 API Key；
2. 把 API Key 告诉我（或直接给我 key 后由我批量补跑）；
3. 阈值按方案：score ≥ 0.1。

## 3. OMIM

1. 打开 https://www.omim.org/ ，注册免费账号并申请 API Key（academic 即时审批）；
2. 或直接网页检索各疾病词，记录 MIM 号与"Gene/Locus"关联表截图/导出；
3. 把 Key 或导出文件给我即可。

## 4. CTD（Comparative Toxicogenomics Database）

1. 打开 https://ctdbase.org/ → **Batch Query** 工具；
2. Input type 选 `Disease`，逐词粘贴 6 个检索词（或 MeSH 号：HUS=D006463、TTP=D011697、Snake Bites=D012909）；
3. Report 选 `genes_curated`，Format 选 `TSV`，下载为 `ctd_<词>.tsv`；
4. 按 inference score 排序的字段会包含在导出中。

## 交付后我会自动执行

合并四库结果 → UniProt ID 标准化 → 与现有 750 基因总表取并集/交集 → GeneCards ≥中位数（或≥10）主阈值敏感性分析 → 更新 PRISMA 图 B 线与数据管理表。
